# TEL 計分面板（輔助人員用）

在平板或手機上記每一場的進球數、沒進的框，並可以錄音。**完全離線**，賽場上不用網路。

**安裝網址（賽前有網路時打開一次，加入主畫面）：https://yxyang960102.github.io/TEL_ScoreBoard/**
所有程式都在 `index.html` 一個檔案裡，沒有用到任何網路上的資源。

## 怎麼給隊友

### 方式 A：直接給檔案（Android、電腦）

1. 把 `index.html` 用 LINE、雲端硬碟或 USB 傳給隊友。
2. Android：用 **Chrome** 打開這個檔案（檔案管理 → 用 Chrome 開啟）。電腦：直接雙擊用瀏覽器打開。
3. 紀錄存在那台裝置的瀏覽器裡，下次用同一個瀏覽器打開同一個檔案就還在。

限制：
- **iPhone / iPad 不能用這個方式**：「檔案」App 只會顯示預覽，不會執行程式。
- 直接開檔案時，手機常常拿不到麥克風權限。錄不了音的話，改用「標記沒進」打字記錄。

### 方式 B：安裝到主畫面（iPhone、iPad、Android 都可以，建議）

賽前**有網路時**做一次，之後在賽場上完全離線使用，錄音也可以用。

1. 把這個資料夾放到 GitHub，開啟 GitHub Pages：Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)`，存檔。
   已經開好了：https://yxyang960102.github.io/TEL_ScoreBoard/ （repo：YXYang960102/TEL_ScoreBoard，public）。
2. 隊友在有網路時用手機打開這個網址：
   - iPhone / iPad：用 **Safari** 打開 → 分享按鈕 → 「加入主畫面」。
   - Android：用 **Chrome** 打開 → 右上角選單 → 「安裝應用程式」或「加到主畫面」。
3. 從主畫面的「TEL 計分」圖示打開一次，確定畫面正常。之後就不需要網路。
4. 第一次按「錄音」會問麥克風權限，選允許。

改了程式之後，把 `sw.js` 裡的 `VERSION` 和 `index.html` 標題旁的版本（例如 `v3`）都改成新的再推上去。目前是 v5。隊友**有網路時打開一次**就會換成新版（畫面會自動重新整理一次）；沒網路時用手機裡存的那一版。標題旁的版本號可以確認現在是哪一版。

如果手機一直卡在舊版：先在「紀錄」頁**匯出全部**，再把主畫面的圖示刪掉、用 Safari / Chrome 重新加入主畫面（iPhone 刪掉圖示會連紀錄一起刪，所以一定要先匯出）。

## 怎麼用

### 計分
- 最上面填 **場次**（例如 Q12），選 **上半場 / 下半場**、**球色**。
- 框的排列跟場地一樣：最上面是加分框 Q W E，下面 3×3，編號跟 Dashboard 一樣（左邊一行由下往上是 1 2 3，中間 4 5 6，右邊 7 8 9）。
- **點一下 +1，長按 −1**。滿了再點會維持不變，只有長按才會減。**加分框 Q W E 最多 1 顆**（只能射一次）。顏色代表進了幾顆：

  | 半場 | 0 顆 | 1 顆 | 2 顆 | 3 顆 |
  |---|---|---|---|---|
  | 上半場 | 白 | 綠 | 黃 | 紅 |
  | 下半場 | 白 | 綠 | 紅 | — |

- 點錯可以按「復原」。
- **指定得分格**：比賽開始前 60 秒亮燈的那個加分框，在上面選 Q / W / E。第一次點加分框時會自動選成那一格。只有亮燈那格算分，其他加分框不算。

### 總得分（照官方規則 2026_rule_1112.pdf 計分方式）
框下面會即時顯示**總得分**、各項分數和**有沒有連線**（連到的框會有橘色外框）。

| 項目 | 上半場 | 下半場 |
|---|---|---|
| 九宮格 | 每顆 2 分，每格最多算 3 顆（最高 54） | 每顆 2 分，每格最多算 2 顆（最高 36） |
| 指定得分格（亮燈的加分框） | 每顆 4 分，最多 3 顆（12） | 每顆 4 分，最多 2 顆（8） |
| 連線（同一條線 3 格都有球） | 不計分（只顯示） | 橫線 +2、直線 +4、斜線 +8，每條只算一次（最高 34） |
| 加乘 | — | 第一回合：上半場第 5–8 名 ×1.2、第 9–12 名 ×1.1（在總得分旁邊選） |

規則範例檢查：下半場 1、5、9 各有球（共 5 顆）→ 九宮格 10 + 斜線 8 = 18 分，跟規則裡 B 隊的例子一樣。
黃牌、救援卡等不影響分數的項目沒有算進去。
- 半場打完按 **儲存這半場**，計分會清空，準備下一個半場。換半場時還沒儲存，會先問你要不要儲存。

### 偵察（記錄其他隊伍）
- 切到「**偵察**」分頁，填 **隊伍**（輸入過的隊名下次可以直接選）、**場次**、**上／下半場**。
- 下面的框跟「計分」一模一樣：點一下 +1、長按 −1，一樣算總得分和連線。偵察的計分跟我們自己的計分分開存。
- **畫自動路徑**：場地圖是規則「圖(一)競賽場地俯視圖」的 A 場地（九宮格得分區＋機器人作業區）。
  - 手指或觸控筆直接在圖上畫，線頭有箭頭表示方向，點一下是一個標記點。
  - 三種筆色（紅、藍、黑），例如紅色畫自動路徑、藍色畫手動路線。
  - 「復原一筆」刪掉最後一條線，「清除路徑」全部清掉。
  - 圖上不能捲動畫面，要捲動請按圖的兩旁。
- **戰術備註**：例如「右邊起始、先打下排」。
- 按「**儲存這筆偵察**」存起來；隊伍、計分、路徑、備註會清空，場次和半場保留。
- 「紀錄」分頁最下面是**偵察紀錄**，可以選隊伍只看那一隊；每筆有路徑縮圖，按「**存成圖片**」可以存成 PNG 傳給隊友。

### 記錄沒進的球
- **錄音**：按下方的「錄音」開始，直接說「4 號框、4.5 米、紅球、偏高」，再按一次停止。每段錄音都會記下時間、場次、半場、球色。
- **標記沒進**：切到「標記沒進」再點框，選球色、距離、寫備註，也可以在裡面錄一段語音，最後按儲存。框的右上角會出現 ✕ 次數。

### 紀錄、匯出
- 「紀錄」分頁可以看到每個儲存的半場（小格子顯示每個框幾顆）、所有沒進、語音紀錄（可以直接播放錄音），和偵察紀錄。
- **匯出全部（含錄音）**：一個 `.json` 檔，包含計分、沒進紀錄、錄音和偵察紀錄（含畫的路徑），回去後可以在電腦上用「匯入紀錄」打開。
- **匯出表格 CSV**：用 Excel 打開，每個半場一列、每個沒進一列、每筆偵察一列（最後兩欄是隊伍、路徑筆數；路徑本身在 JSON 和圖片裡），方便回去對照射擊表調整。
- iPhone 匯出時會跳出分享選單，選「儲存到檔案」或傳給自己。
- 「刪除全部紀錄」會清掉這台裝置上的所有資料，刪之前請先匯出。

## 資料存在哪裡

- 計分、文字紀錄和偵察紀錄（含路徑座標）：瀏覽器的 localStorage。
- 錄音：瀏覽器的 IndexedDB。
- 都只存在那一台裝置。換手機、清除瀏覽器資料、用無痕模式都會不見，所以每場比賽後記得匯出。
